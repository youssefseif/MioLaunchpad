# MioLaunchpad

Un sostituto minimale, fluido e nativo per il Launchpad di macOS, sviluppato in Swift e AppKit.

## Caratteristiche
- **Separazione Smart**: Suddivide le app personali da quelle native di sistema.
- **Ordinamento per data**: Organizza le applicazioni in base alla data di aggiunta al sistema.
- **Griglia 7x8**: 56 icone per schermata con cambio pagina via swipe o frecce direzionali.
- **Ricerca istantanea**: Digita direttamente per filtrare i programmi installati.

## Integrazione Trackpad (Glide)
L'applicazione è configurata per essere aperta comodamente tramite gesture a 4 dita grazie all'utility open-source **Glide**.
